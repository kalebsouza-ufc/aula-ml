# Pré-requisitos
- Antes de começar, você precisa ter essas ferramentas intaladas em seu computador
1. Ferramentas usadas durante o processo:
    - python >= 3.14
    - dvc >= 3.67
    - git >= 2.56

# Configuração
A configuração de acesso do armazenamento DVC está localizando em `.dvc/config`

# Restauração
caso queira realizar a restauração de algum modelo em específico, após clonar este repositório, digite:

```bash
git switch --detach modelo-<versão>
```

e digite

```
git tag --list
```
caso queria saber as versões já lançadas
